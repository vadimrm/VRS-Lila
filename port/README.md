# Порт «Лилы» (DOS, 1995–1996) на Windows

Рабочие порты VR-системы **ЛИЛА** Вадима Мадгазина (© 1995, 1996) с 16-битного
DOS (Borland C, VGA 13h) на 32-битную Windows. Собираются компилятором
MinGW-w64 (GCC), внешних зависимостей нет — только системные WinAPI/WinMM.

| Программа | Оригинал | Что это |
|---|---|---|
| `install/lila_install.exe` | `LILA/49i/VRS49I.C` | консольный генератор данных |
| `vrs57/data/lila57.exe` | `LILA/57/` | «Virtual Reality Shell 0.57» — вариант с курсором/карандашом и редактором ПП1 |
| `vrs58/data/lila58.exe` | `LILA/58/` | «Virtual Reality System 0.58» — вариант с ножом, броском, осколками и гравитацией |

**Готовые релизы** (exe + все файлы данных, скопировать куда угодно и запускать):
`exe/v49i_win_1.00/`, `exe/v57_win_1.03/`, `exe/v58_win_1.03/`.
Версия порта показывается в диалоге Menu → About («Оригинал: версия для
DOS, 1995–1996 + Порт на Windows: 1.01, 2026»). При каждом коммите версия
увеличивается (1.02, 1.03...) и переименовываются папки тех продуктов, которые
изменились (год/версия порта задаются макросами `WINPORT_VER`/`WINPORT_YEAR`
в `port/common/dos2win.h`; инсталлятор несёт свою версию).

**Шрифты**: 57-я версия использует подлинный шрифт автора `LILA/FONT.LII`
(1995), 58-я — синтезированный порт-инсталлятором (заменяется вашим файлом,
если положить его в data).

**help.txt** (UTF-8 с BOM) — текст для меню Help в окне Windows; это копия
help.doc, можно свободно редактировать. Файл help.doc (CP866) по-прежнему
читает сама игра для 3D-журнала по F1.

Оригинальные исходники в папке `LILA\` не изменялись — портированные копии
живут в `port\vrsNN\` (правые части файлов содержат пометки `//PORT:`).

## Сборка

Нужен MinGW-w64 **i686** (32-битный таргет — ради совместимости с Windows 7/8).
Портативная версия ставится так (без прав администратора):

1. Скачать zip-сборку winlibs i686 msvcrt (проверено: GCC 15.2.0).
2. Распаковать в `C:\tools\` так, чтобы получилось `C:\tools\mingw32\bin\gcc.exe`.
3. Добавить `C:\tools\mingw32\bin` в пользовательский PATH.

Сборка всего одной командой:

```bat
port\build_all.bat
```

(или вручную: `gcc -O2 -Iport\common -o ... -lm -lwinmm -mwindows -static-libgcc`,
см. `build_all.bat`).

## Генерация данных (lila_install.exe)

Консольная программа-инсталлятор, порт `VRS49I.C`, запускается **из папки
данных** игры:

```bat
cd port\vrs58\data
..\..\install\lila_install.exe --all
```

| Опция | Файлы | Что генерирует |
|---|---|---|
| (без опций) | `keyboard.lii` (256 Б), `sinus.lii` (16388 Б) | **бит-в-бит как оригинал VRS49I**: таблица перекодировки скан-кодов (scod.h восстановлена по семантике ISR) и таблица синусов 16.16 |
| `--font` | `font.lii` (2048 Б) | синтезированный шрифт 8×8 CP866 (латиница/кириллица/псевдографика) — оригинальный font.lii в дереве отсутствовал |
| `--pp` | `PP\far0.pp`, `PP\far1.pp` (64782 Б) | процедурные картинки дали: облака и горы (оригинальные PP в дереве отсутствовали) |
| `--all` | всё сразу | |

`syspal.lii` программа создаёт сама при первом запуске (как в оригинале).
`ll.lii`, `vrs.ll`, `ap1.ll`, `help.doc` — копируются из `LILA\58\` и `LILA\57\`.

## Запуск

Запускать exe **из папки данных** (она же рабочая папка):

```bat
cd port\vrs58\data
lila58.exe           % звук включен по умолчанию (S - вкл/выкл)
lila58.exe PP\my.pp  % свой файл дали вместо PP\far0.pp
```

Окно 640×400 с меню **Menu → About / Help / Settings**. Help показывает тот же
текст help.doc, что игра выводит в 3D по F1. Settings — два горизонтальных
слайдера: громкость звука (0..100%, по умолчанию 20%) и скорость рендера
(10..90 FPS, по умолчанию 50) с цифрой реального FPS; в промежутках ожидания
процессор спит. Звуковой секвенсор тикает каждые 4 мс в аудио-потоке —
независимо от частоты кадров (как ISR 250 Гц в оригинале), вывод буферизуется
waveOut. Вывод — двойная буферизация: кадр собирается в невидимом буфере и
показывается одной операцией, без мигания. При изменении размера кадр 320×200
масштабируется с сохранением пропорций 8:5. Закрытие окна = выход.

### Горячие клавиши (см. также LILA/57/HELP.DOC)

Общие: **F10** — выход, **стрелки/Add-клавиши** — движение и повороты,
**Tab** — клиппинг, **P** — панель параметров, **S** — звук, **F1** — хелп,
**1...9** — фон/варианты, **`<`/`>`** — размер экрана рендера (80×50...320×200).

58: **Space** — бросок ножа в цель, разрыв на осколки; **0** — космос↔земля.
57: **Enter** — выбор панели, **Ins/Del** — видимость панелей ПП1, F2–F9 — редактор.

## Архитектура порта

```
port\
  common\vrsport.h    — типы/макросы совместимости (far/near пустые, fix-математика
                        на 64-бит промежутках вместо VRS54A.OBJ, FP_OFF/FP_SEG/MK_FP)
  common\dos2win.c/h  — бэкенд: окно Win32 + StretchDIBits (LUT палитры),
                        клавиатура через WM_KEYDOWN (те же set-1 скан-коды, что
                        давал ISR int 9), мышь Raw Input (семантика int 33h),
                        спикер → waveOut (квадрат-меандр, частота 1193180/div),
                        findfirst→FindFirstFile, время → timeGetTime
  common\font_cp866   — (внутри lila_install.c) синтез шрифта CP866
  install\lila_install.c
  vrsNN\              — портированные модули игры (vrsNN.c/h/c/r/s/ap1)
  vrsNN\data\         — готовые данные + собранный exe
```

Главный цикл «витка» сохранён 1:1: `WinPump → FillKbbufFromWin → FistVRStask
(время+секвенсор) → KeyboardBufferScan → SystemMessageFiltr → AP-задачи →
VideoShow → LastVRStask → MessageDeleter → WinFrameEnd`.

### Основные замены DOS→Windows

- VGA 13h (`A000`, DAC-порты 3C7-3C9) → буфер 64000 Б + LUT + StretchDIBits;
- прерывания int 8/9/0 и PIT → монотонные часы, очередь клавиатуры, guarded fixdiv;
- `int 33h` (мышь) → Raw Input + счётчики нажатий;
- спикер (PIT канал 2 + порт 61h) → waveOut-поток с квадрат-волной;
- `far/huge` менеджер 64к-блоков → плоская арена 8 МБ (алгоритм сохранён);
- `VRS54A.OBJ` (asm) → чистый C (fixmul/fixdiv и 6 z-циклов рендера
  переведены по C-эквивалентам из комментариев оригинала);
- `word` теперь `unsigned short` (в Turbo C `unsigned int` был 16-битным —
  это критично для 16-битной арифметики углов-лидусов и времени);
- y-буфер рендера — 16-битный `short` (блок памяти 2 байта/пиксель).

### Известные отличия поведения

- `fixdiv` при переполнении даёт насыщение (в DOS ловился int 0 и делимое
  делилось пополам — числа близки, но не идентичны);
- таймер: реальное время в мс вместо кванта 4 мс (движение плавнее);
- шрифт и картинки дали синтезированы — выглядят иначе, чем у автора;
- чувствительность мыши нормализована под Raw Input.

### Совместимость

Собрано на GCC 15.2.0 (i686, msvcrt), исполняется как 32-бит PE — должно
работать на Windows 7/8/10/11 без установленных рантаймов. Проверено на
Windows 10 x64 (окно, рендер, движение, повороты, звук через waveOut).
